### ✅ FIXED-2 收帧索引缺少上限检查

**位置**：`App/hy_hmi/hy_hmi.c` → `HAL_UART_RxCpltCallback()`

接收缓冲区 `g_usart_rx_buf[30]` 仅 30 字节，原实现索引只由帧尾 `FF FF FF` 复位，无长度上限，最坏可越界约 4 KB。

**修复**：

```c
else
{
    //越界保护：接收缓冲仅 30 字节，超长帧直接丢弃并复位状态机
    if((g_usart_rx_sta & 0x0FFF) < sizeof(g_usart_rx_buf))
    {
        g_usart_rx_buf[g_usart_rx_sta & 0x0FFF] = RxBuffer[0];
        g_usart_rx_sta++;
    }
    else
    {
        g_usart_rx_sta = 0;
    }
}
```

### ✅ FIXED-3 `strchr()` 返回值未判空

**位置**：`App/hy_file/hy_file.c` → `Save_Data()`

原实现 `p = strchr(save_data, '-') - 2;` 在序号格式异常（不含 `-`）时会对 `NULL-2` 解引用，触发 HardFault。

**修复**：

```c
p = strchr(save_data, '-');		//判空：序号格式异常时直接返回，避免解引用非法地址
if((p == NULL) || (p < save_data + 2))
{
    return FR_INVALID_PARAMETER;
}
p -= 2;
```

**同时修复**：`group[2]` / `slot[2]` 改为 `group[4]` / `slot[4]` 并 `memset` 清零——原实现用 `strncpy` 填满 2 字节后直接交给 `atoi()`，缺少字符串终止符。

### ✅ FIXED-4 TIM2 中断内执行 1000 次 SPI 读取，中断耗时远超周期

**位置**：`Core/Src/main.c` → `HAL_TIM_PeriodElapsedCallback()`

原实现（2026-04-07 引入）：

```c
for (int i = 0; i < 1000; i++) {
    v_data += hy_ad7190_get_val();
}
v_data = v_data / 1000;
```

按 SPI3 分频 16（APB1 42 MHz ÷ 16 = 2.625 MHz）、单次约 4 字节 ≈ 12 µs 估算，1000 次约 **12 ms**，而中断周期仅 **1 ms**（重装载 999）→ 中断长期无法返回、采样节拍丢失、RTOS 调度延迟，并可能触发 IWDG 复位。

**修复**：恢复为"单次读取 + 小信号求均值 / 大信号取峰值"双策略，阈值按 2026-04-07 的标定系数（1096 计数/g）取 `1096*10`（10 g）与 `1096*5000`（5000 g 上限）：

```c
v_data = hy_ad7190_get_val() - zero;

if(v_data < 1096*10 && temp_val == 0)	//一轮数据获取中没有超过10g需要进行滤波
{
    mean_val += v_data;
}
else if(v_data > temp_val)		//一轮数据获取中有一次超过10g就取最大值
{
    temp_val = v_data;
}
...
x2 = temp_val;
```

## 附：已确认**不是**缺陷的实现

为避免后续维护者误改，以下实现经核对是正确的：

1. **收帧状态机的帧尾判定**：`AA 55` 帧头后，3 个连续 `0xFF` 使 `g_usart_rx_sta` 依次变为 `0x8000 → 0xC000 → 0xD000 → 0xE000`，与判据 `(g_usart_rx_sta & 0xE000) == 0xE000` 吻合，逻辑正确。
2. **`w25q64_write()` 的自动擦除**：先按地址范围计算涉及扇区并逐个擦除，再按 256 字节分页写入，流程正确。
3. **`slot_flush_reorder()` 的环形重排**：未满 300 点时按顺序拷贝并补 0，满 300 点时按写指针环形展开，顺序正确。
4. **LED 低电平点亮**：`hy_pci_led1(1)` 输出 `GPIO_PIN_RESET`，与硬件设计一致。
5. **`Mount_FatFs()` 的自动格式化分支**：仅在 `FR_NO_FILESYSTEM` 时触发，不会误格式化正常 U 盘。
